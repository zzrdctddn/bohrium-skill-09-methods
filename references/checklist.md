# 方法实验章自检清单（逐项打钩）

## 写得全（六要素）
- [ ] 六要素齐全：步骤/设置/参数/数据/对照/复现与限制
- [ ] 缺失要素标 `missing_element` 并追问
- [ ] 步骤拆到单步，含输入/操作/输出/判断条件
- [ ] 训练/验证/测试分开描述，重复次数写明

## 写得准（溯源与一致）
- [ ] 每个数值/参数在溯源表有来源与来源位置
- [ ] 正文数值与溯源表逐项对齐
- [ ] 来源冲突标 `conflict`，未擅择一
- [ ] 数据集版本、规模、预处理、划分比例与随机方式明确
- [ ] 训练与评测条件与配置/日志一致，无串台
- [ ] 无材料外新增数值、参数、版本

## 做得着（可复现）
- [ ] 可复现清单含代码版本/commit、环境与依赖版本
- [ ] 随机种子、完整命令、数据获取方式、硬件齐全
- [ ] 缺失项标 `missing` 并进人工确认，未臆造版本号/种子/命令

## 说得住（对照、限制与缺口）
- [ ] 对照实验写清基线及版本、同预算、指标与统计方式
- [ ] 不可比对照标 `not_comparable`，未写成有效性断言
- [ ] 每条限制绑定具体失效场景与适用范围，非套话
- [ ] 缺口转成具体追问清单，进 `human_review_items`

## 结构与边界
- [ ] `result.json` 含 case_id/status/artifact/证据映射/uncertainties/human_review_items/change_log/self_check
- [ ] 有可编辑成稿，非 PDF/截图
- [ ] 无编造 benchmark 分数
- [ ] `status` 诚实（success/partial/blocked），partial/blocked 写明原因
- [ ] 抽取与核对分离，所有改动有 `change_log`
- [ ] 示例标注为示意、非真实案例
